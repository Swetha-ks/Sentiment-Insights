# Sentiment Insights

A Flask-based web application that combines **machine learning** and **natural language processing** to analyze sentiment.  
It integrates TensorFlow models, NLTK sentiment analysis, and SQLAlchemy for database management.

---

## 🚀 Features
- Text sentiment analysis using NLTK’s VADER
- Image handling with Pillow
- Deep learning models with TensorFlow/Keras
- SQLite database integration
- Flask web interface with templates

---

## 📂 Project Structure
- `app.py` → Main Flask application
- `config.py` → Configuration settings (database URI, secret key, etc.)
- `requirements.txt` → Dependencies
- `templates/` → HTML templates for the web app
- `static/` → Static files (CSS, JS, uploads)
- `README.md` → Project documentation
